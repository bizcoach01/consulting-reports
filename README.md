## GitHub Pages 배포
1. GitHub에서 `consulting-reports` 저장소 생성
2. 이 폴더의 내용 전체 업로드
3. Settings → Pages
4. Build and deployment → Deploy from a branch
5. Branch: `main`, Folder: `/(root)` 선택 후 Save
6. 잠시 후 GitHub Pages 주소에서 확인
